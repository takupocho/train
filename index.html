列車またはトラス橋を選び、位置と向きを指定して Google Earth Pro 用の KML / KMZ ファイルを書き出します。

配置するもの
編成
トラス橋の寸法
初期値はいただいた写真から、列車（20m）を定規にして実測した値です（支間68m / 桁高8m / 幅5.8m / 12パネル）。真上の写真からは支間66m、真横からは70mと読めたので支間長は±3m程度の誤差があります。パネル数が一番不確かで、端柱の傾きからは15、斜材の角度からは13と出たため中間の12にしました。上のプレビューを写真と見比べて合わせてください。衛星写真に切り替えれば、地図の緑の枠を実際の橋脚に合わせられます。
先頭車両（1両目）の位置
Googleマップで開く ↗
Googleマップで場所を右クリック→座標をクリックするとコピーされます。ここに貼り付ければ自動で下欄・地図に反映されます。
鉄橋の上など、地表より高い場所に置きたい場合はプラスの値を入れてください（例: 橋の高さが6mなら6）。マイナス値で下げることもできます。列車の y=0 とトラスの下弦材は同じ高さなので、両方に同じ値を使えば桁の上に列車が乗ります。
出力形式
オンにすると、回転を適用済みのメッシュを書き出し、doc.kml の heading は 0 になります。読み込み側が自前の回転でモデルを歪ませる場合に有効です。オフにするとメッシュは向き0のままで、doc.kml の heading に方位を持たせます。

入力内容はこのブラウザにCookieとして保存され、次回開いたときに復元されます。
